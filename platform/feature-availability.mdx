This page is for anyone who cannot find a feature mentioned in the docs. It lists what is available in the Console today and what is still limited. Other guides link here instead of repeating status notes.

## Status labels

| Label | Meaning |
|-------|---------|
| **Available** | Part of the Console for standard workspaces |
| **Preview** | Works but is limited, or may change. Not shown in the Console for every workspace. |
| **Rolling out** | Being turned on step by step. You may not see it yet. |
| **Demo only** | Works with sample data only. Not for real data. |

## What is available

| Feature | Status | Where to find it | Notes |
|---------|--------|------------------|-------|
| Workflows and Command Center | **Available** | **Workflows** (opens the Workflow Studio editor), **Command Center** | |
| Connections and MCP instances | **Available** | **Connections**, **MCP** | |
| Triggers | **Available** | A workflow's **Setup → Triggers** tab, and **Runs → Triggers** | Schedules, app events and HTTP calls are generally available. Phone triggers need voice calling, which is not turned on in every workspace yet. See [Triggers](/integrations/triggers). |
| LLM providers | **Available** | **Models**, **Connections** | |
| Billing and credits | **Available** | **Billing** in the sidebar: **Overview**, **Plans**, **Usage** | See [Billing and credits](/platform/billing-and-credits). |
| Analytics | **Available** | **Analytics** in the **Run** group | See [Analytics](/platform/analytics). |
| Agents, Apps and Marketplace | **Available** | **Agents**, **Apps**, **Marketplace** in the sidebar | |
| Tools library | **Available** | **Tools** in the sidebar | A read-only library of tools you can add to a workflow. It does not build servers. To add your own MCP server, see [Custom MCP servers](/integrations/custom-mcp-servers). |
| Runs, Databases and Storage | **Available** | **Runs**, **Databases**, **Storage** in the sidebar | |
| Autopilot | **Available** | **Open chat** in the top bar. It opens a side panel beside the page you are on. | See [Autopilot and chat](/ai/autopilot-and-chat). |
| Slack connector | **Available** | **MCP** catalog | See [slack](/connectors/slack). |
| Memory, Knowledge and Sync | **Coming soon** | Listed as **Soon** under **Data** in the sidebar. Memory works through the API only. | See [Memory](/ai/memory). |
| Referrals | **Rolling out** | Not in the sidebar. Press **Ctrl+K** (**Cmd+K**) and look under **More**, when the program is turned on | See [Referrals and affiliates](/platform/referrals-and-affiliates). |
| Healthcare connector | **Demo only** | **MCP** catalog | Sample data only. Never use real patient data. |

## How to check your workspace

- Look at the Console sidebar. Features that are not turned on for you do not appear.
- Some pages and tabs depend on your role. See [Roles and permissions](/platform/roles-permissions).
- If an API call says a feature is disabled, it is not turned on for your workspace. Contact [support](mailto:support@agentruntime.io).
