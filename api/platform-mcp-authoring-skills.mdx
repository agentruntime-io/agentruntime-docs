## Typical order

1. `ar_get_started` — tenant, playbooks, `embedded_schema_tools`
2. Load **platform-design** SKILL, then tenant-data → workflow → surfaces as needed
3. `workflows_validate` with `tenantdata_schema` before run
4. For Surfaces apps: publish workflows first, then set **`workflow_ref` to published UUIDs** (avoid **Import pending** in Console)
