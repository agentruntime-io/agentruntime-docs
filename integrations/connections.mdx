title: Connections
description: Save Google, WhatsApp, and API-key credentials once, then reuse them across connectors and workflows.

A **connection** is a set of saved credentials for an outside service: a Google sign-in, a WhatsApp Business account, an API key, or a database connection string. This page is for anyone who needs to add, test, rotate, or delete credentials in the [Console](https://console.agentruntime.io).

Secrets are stored in the Vault. After you save them, the Console does not show them in plain text again.

A connection does nothing by itself. You attach it to a connector through a **config profile** on an [MCP instance](/integrations/mcp-instances), and a workflow step then uses that instance.

## Before you begin

- A workspace selected in the Console header. Connections belong to a workspace.
- The **project_contributor** role or higher. Without MCP write permission, the buttons on the page are disabled.

## What the Connections page shows

Open **Connections** in the sidebar. You will see:

- **New custom connection** and **Add from template** buttons at the top right.
- An **Accounts** section with a **Sign in with Google** button, when Google sign-in is available for your workspace. The Google card shows how many Google accounts you have.
- A **Saved connections** list, grouped by provider, with a **Search connections…** box. Each row shows when it was last updated and how many instances use it. A row marked **Unused** is not attached to any instance yet.

Click a row to open its details. A details panel shows the credential type, a **Test** button, a **Rotate** button, a **Used by** list, and **Delete connection**.

## Add a Google account

One Google sign-in can power several Google connectors, so you choose the services up front.

<Steps>
  <Step title="Start the sign-in">
    On **Connections**, click **Sign in with Google** (or **Add from template**, then click **Sign in** on the **Google** row under **Accounts**).
  </Step>
  <Step title="Name it and pick services">
    Enter a **Display name** (for example `Work Google`), then tick the services you need, such as Gmail or Sheets. **Select all** and **Clear all** help with long lists.
  </Step>
  <Step title="Continue to Google">
    Click **Continue to Google**, sign in, and approve the permissions. You return to the Console.
  </Step>
</Steps>

You should now see the account under **Accounts**. Open it to see **Enabled services** and **Used by MCP instances**. To add a service later, open the account and click **Update permissions**. If Google access stops working (for example, the user revoked it), open the account and click **Reconnect**.

If **Sign in with Google** is missing or **Continue to Google** is disabled, Google sign-in is not set up for your workspace. [Contact support](mailto:support@agentruntime.io).

See [Google Workspace](/integrations/google-workspace) for the connectors that use it.

## Add WhatsApp

1. Click **Add from template**.
2. On the **WhatsApp** row under **Accounts**, click **Connect**.
3. Choose **Connect with Meta** and click **Connect WhatsApp Business** to use Meta's signup, or choose **Paste API keys** and enter the **Access token**, **WhatsApp Business Account ID**, and optionally the **Phone number ID**. Then click **Save WhatsApp connection**.

If the **Connect** button is disabled, WhatsApp connect is not set up for your workspace. See the [WhatsApp connector](/connectors/whatsapp) for tools, templates, and messaging.

## Add an API key or connection string

Most connectors (Resend, GitHub, Shopify, Postgres, Notion, and more) use a key, token, or connection string.

<Steps>
  <Step title="Pick a template or start from scratch">
    Click **Add from template**. The dialog has a **Search templates…** box, an **Accounts** section (Google, WhatsApp, and Notion), and an **API keys & credentials** list. Find your service in that list and click **Connect** on its row. If it is not listed, close the dialog and click **New custom connection**. A few rows are greyed out and cannot be picked.

    <Frame caption="Add from template: the Accounts section">
      <img src="/images/integrations/connections-add-from-template.png" alt="The Add from template dialog with a Search templates box, the Accounts section listing Google with a Sign in button, and WhatsApp and Notion with Connect buttons, and the start of the API keys and credentials list" />
    </Frame>

    <Frame caption="Add from template: the API keys & credentials list">
      <img src="/images/integrations/connections-api-keys-templates.png" alt="The API keys and credentials list in the Add from template dialog, two columns of services such as Activecampaign, Airtable, Apify, Brave and Calendly, each with the number of fields and a Connect button" />
    </Frame>
  </Step>
  <Step title="Enter the credentials">
    For a template, fill in the fields shown. For a custom connection, enter a **Display name**, then add one row per secret: a key name such as `api_key` and its value. Use **Add field** for more rows.
  </Step>
  <Step title="Save">
    Click **Save**. You should see a "Connection saved" message and the connection in **Saved connections**.
  </Step>
</Steps>

## Use a connection in a connector

Open **MCP**, open your instance, and on **Instance config** choose the connection in a profile, then click **Use this profile for workflows**. The steps are in [MCP instances](/integrations/mcp-instances).

## Manage a connection

Click the connection's row to open its details.

| Task | How |
|------|-----|
| **Check it still works** | Click **Test**. A "Resolve test OK" message means the credentials can be read. |
| **Rename** | Click the pencil icon next to the name. |
| **Change or rotate a key** | Click **Rotate**, edit the values, and click **Save to Vault**. Update the key in the outside service first if you are replacing it. |
| **See where it is used** | Open the **Used by** section. |
| **Delete** | Click **Delete connection** and confirm. |

<Warning>
  Deleting a connection also deletes the config profiles that use it. Instances that relied on it stop working until you attach a new connection. Check **Used by** first.
</Warning>

## Common problems

| Problem | What to do |
|---------|------------|
| Buttons are disabled | Select a workspace in the header, and make sure you have MCP write permission. |
| "Workspace required" message | Pick a workspace with the control in the header. |
| A Google connector stops working | Open the account and click **Reconnect**. |
| A tool says it has no credentials | Attach the connection to the instance's active profile. See [MCP instances](/integrations/mcp-instances). |
