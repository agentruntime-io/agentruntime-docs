A **connector** is a set of tools for one outside service, such as Gmail or Postgres. This page helps you find connectors and shows common ways to combine them. It is for anyone planning which services a workflow will use.

The platform catalog includes more than 400 connectors. This page lists the ones that have their own guide in the **Connectors** section (`/connectors/{slug}`), with setup, tools, and configuration for that connector. To see everything available to you, open **MCP** in the [Console](https://console.agentruntime.io), click **Add connectors**, and browse or search the **App catalog**.

## Common patterns

Most production workflows combine a few connectors with LLM and human steps. Start from a pattern, then open the connector pages for tool names and sign-in details.

| Pattern | Flow | Example guide |
|---------|------|---------------|
| **Webhook → store → notify** | Inbound event → validate → database INSERT → optional digest email | [Form → Postgres → Resend](/guides/form-webhook-postgres-resend-digest) |
| **Event → lookup → message** | External webhook → MCP fetch → customer notification | [Shopify → WhatsApp](/guides/shopify-order-whatsapp) |
| **Conversation → agent → person** | Customer message → agent reply in one ongoing session → hand-off to staff → back to the agent | [WhatsApp customer chat](/guides/whatsapp-customer-chat) |
| **Fetch → LLM → human → action** | Read source data → draft with LLM → Command Center approval → MCP write | [GitHub PR review](/guides/github-pr-review) |
| **Schedule → query → summarize → email** | External cron → SQL report → LLM narrative → Gmail/Resend | [Postgres weekly report](/guides/scheduled-postgres-gmail-report) |
| **Webhook → CRM + log** | Lead form → CRM contact + parallel audit row (Notion/Sheets) | [Lead sync](/guides/lead-sync-activecampaign-notion) |
| **Approve then send** | Draft → a **Human** step → outbound MCP (any channel) | [Workflow patterns](/workflows/patterns#approve-then-send) |

```mermaid
flowchart TB
  subgraph ingest [Ingest]
    WH[Inbound webhook]
    WH --> V[Validate]
  end
  subgraph store [Store]
    V --> DB[(Postgres / Sheets / Notion)]
  end
  subgraph act [Act]
    V --> CRM[CRM / Shopify / GitHub]
    DB --> LLM[LLM summary]
    LLM --> H[Human approval]
    H --> OUT[Email / WhatsApp / Comment]
  end
```

## How to add a connector

1. Read the [Integrations quickstart](/integrations/quickstart).
2. Create a [connection](/integrations/connections) if the connector needs credentials.
3. In **MCP**, click **Add connectors**, select the connector, and click **Add to workspace**.
4. Attach the connection on the instance's **Instance config** page. See [MCP instances](/integrations/mcp-instances).
5. Open the connector's guide above for tool names and settings.
6. For multi-connector recipes, see the [end-to-end guides](/guides/overview).

If a connector you need is not in the catalog, you can [register your own MCP server](/integrations/custom-mcp-servers).
