title: ClickUp connector
description: Create and update ClickUp tasks, lists, comments, docs, time entries, and chat messages from AgentRuntime workflows.

The **clickup** connector connects your workflows to the [ClickUp API](https://clickup.com/api). Use it to turn requests into tasks, keep statuses in sync with other tools, post updates as comments, track time, and read or write ClickUp Docs and Chat.

## Prerequisites

- A ClickUp account with access to the workspaces and lists you want to automate.
- A ClickUp **personal API token** (starts with `pk_`).
- The **project_contributor** role or higher in your workspace, which lets you manage connections and MCP instances. See [Roles and permissions](/platform/roles-permissions).

## Connect in AgentRuntime

<Steps>
  <Step title="Create a ClickUp API token">
    In ClickUp, open your avatar menu, go to **Settings**, then **Apps**, and generate a personal API token. Copy the `pk_` value.
  </Step>
  <Step title="Add the connector to your workspace">
    Click **MCP** in the sidebar, then **Add connectors**. Find **ClickUp** in the **App catalog**, select it, and click **Add to workspace**. The instance now appears on the **MCP connectors** page. See [MCP instances](/integrations/mcp-instances).
  </Step>
  <Step title="Add your credentials to a profile">
    Open the new instance to reach **Instance config**. Under **Profiles for this connector**, click **New profile**, enter a **Display name**, and on the **Type secrets on this screen** tab fill in `api_key` (your `pk_` token). Set **Status** to **Active — can be used in workflows** and click **Save**. Then click **Use this profile for workflows**.
  </Step>
  <Step title="Test it">
    In **Workflow Studio**, add the `clickup_get_workspaces` tool from your **ClickUp** instance (use **Browse platform MCP** if it is not listed), fill in its arguments, and run the workflow. A successful step means the connection works. This tool has no arguments. The IDs it returns are the starting point for every other tool.
  </Step>
</Steps>

<Note>
  To reuse the same credentials in more than one profile, save them first under **Connections** → **New custom connection**, using the exact key names from [Configuration](#configuration), then choose **Use a saved connection** on the profile instead.
</Note>

## What you can build

- **Support request to task.** A form or chat escalation becomes a task with `clickup_create_task` in your support list, with priority and assignees.
- **Status sync.** When an issue closes in another tool, `clickup_update_task` moves the matching ClickUp task to its done status.
- **Daily digest.** `clickup_get_tasks` reads a sprint list and an LLM step summarizes blockers for the team.
- **Time and comments.** `clickup_create_comment` leaves an agent's notes on a task, and `clickup_start_time_tracking` and `clickup_stop_time_tracking` log work.

## Tools

The **Required arguments** column lists the fields the tool's input schema marks as required. Some of them are optional in practice; if you have nothing to set, pass an empty value such as `""`, `[]`, `{}`, or `false`.

Tools marked **Delete** remove data permanently. Consider a **Human** approval step before them.

To find the IDs you need, call `clickup_get_workspaces`, then `clickup_get_spaces`, then `clickup_get_folders` or `clickup_get_folderless_lists`, then `clickup_get_lists_in_folder`.

## Example

Create a task in a list. `priority` is 1 (urgent) to 4 (low), and `due_date` is a Unix timestamp in milliseconds.

```json
{
  "id": "clickup-task",
  "type": "mcp",
  "name": "Create ClickUp task",
  "tool_name": "clickup_create_task",
  "tool_args": {
    "list_id": "{{input.list_id}}",
    "name": "{{input.title}}",
    "description": "{{steps.llm-draft.result.text}}",
    "priority": 2,
    "status": "to do"
  },
  "depends_on": [
    "llm-draft"
  ],
  "timeout_s": 30
}
```

## Configuration

| Key | Required | Description |
|-----|----------|-------------|
| `api_key` | Yes | ClickUp personal API token (`pk_...`). |
| `api_base` | No | ClickUp API base URL. Default `https://api.clickup.com/api/v2`. |

## Troubleshooting

| Problem | What to do |
|---------|------------|
| `401` or "token invalid" | Generate a new token under **Settings → Apps** and update the profile. |
| "Status not found" | `status` must match a status name defined on that list, exactly. |
| A task or list is not found | Check the ID and that the token's owner has access to that workspace and list. |
| Not all tasks are returned | `clickup_get_tasks` returns up to 100 tasks per page. Increase `page`, starting at 0, until a page comes back short. |
