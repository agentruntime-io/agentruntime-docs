The **browserless** connector uses [Browserless](https://www.browserless.io/) to load web pages in a real headless browser. Use it when a plain HTTP request is not enough: pages that need JavaScript, visual snapshots, PDFs of a page or your own HTML, structured scraping with CSS selectors, and website performance audits.

## Prerequisites

- A Browserless account and **API token** (cloud or your own Browserless deployment).
- If you run your own Browserless, its REST base URL.
- The **project_contributor** role or higher in your workspace, which lets you manage connections and MCP instances. See [Roles and permissions](/platform/roles-permissions).

## Connect in AgentRuntime

<Steps>
  <Step title="Get your Browserless API token">
    Sign in to your [Browserless](https://www.browserless.io/) account and copy your API token. If you use a self-hosted Browserless, note its REST base URL (without a path).
  </Step>
  <Step title="Add the connector to your workspace">
    Click **MCP** in the sidebar, then **Add connectors**. Find **Browserless** in the **App catalog**, select it, and click **Add to workspace**. The instance now appears on the **MCP connectors** page. See [MCP instances](/integrations/mcp-instances).
  </Step>
  <Step title="Add your credentials to a profile">
    Open the new instance to reach **Instance config**. Under **Profiles for this connector**, click **New profile**, enter a **Display name**, and on the **Type secrets on this screen** tab fill in `api_token` (your token) and, only for a self-hosted Browserless, `api_base`. Set **Status** to **Active — can be used in workflows** and click **Save**. Then click **Use this profile for workflows**.
  </Step>
  <Step title="Test it">
    In **Workflow Studio**, add the `browserless_capture_screenshot` tool from your **Browserless** instance (use **Browse platform MCP** if it is not listed), fill in its arguments, and run the workflow. A successful step means the connection works. Use a public page such as `https://example.com`.
  </Step>
</Steps>

<Note>
  To reuse the same credentials in more than one profile, save them first under **Connections** → **New custom connection**, using the exact key names from [Configuration](#configuration), then choose **Use a saved connection** on the profile instead.
</Note>

## What you can build

- **Visual snapshots.** Capture a competitor or status page on a schedule with `browserless_capture_screenshot` and store the image.
- **Report PDFs.** An LLM step writes HTML, then `browserless_generate_pdf` turns it into a PDF you send or file away.
- **Price or content monitoring.** `browserless_scrape_url` reads the elements you pick with CSS selectors; compare with the last run and alert on change.
- **Performance checks.** `browserless_get_website_performance` runs a Lighthouse audit after a deploy so the workflow can flag regressions.

## Tools

The **Required arguments** column lists the fields the tool's input schema marks as required. Some of them are optional in practice; if you have nothing to set, pass an empty value such as `""`, `[]`, `{}`, or `false`.

| Tool | Access | What it does | Required arguments |
|------|--------|-------------|--------------------|
| `browserless_capture_screenshot` | Read | Render a URL or inline HTML to a PNG, JPEG, or WebP screenshot through Browserless. | — |
| `browserless_generate_pdf` | Write | Render a URL or inline HTML to a PDF through Browserless. | — |
| `browserless_get_website_performance` | Read | Run a Lighthouse-backed website performance audit and return JSON metrics. | `url`, `config` |
| `browserless_run_bql_query` | Write | Execute a BrowserQL GraphQL query against Browserless. | `query`, `operation_name`, `variables`, `bql_path` |
| `browserless_scrape_url` | Read | Extract structured fields from a rendered page using CSS selectors through Browserless. | `url`, `elements` |

## Example

Take a screenshot of a public page. The result includes `image_base64`, `content_type`, and `size_bytes`.

```json
{
  "id": "screenshot-home",
  "type": "mcp",
  "name": "Screenshot homepage",
  "tool_name": "browserless_capture_screenshot",
  "tool_args": {
    "url": "https://example.com"
  },
  "timeout_s": 60
}
```

## Configuration

| Key | Required | Description |
|-----|----------|-------------|
| `api_token` | Yes | Browserless API token. It is sent to Browserless as a query parameter. |
| `api_base` | No | Browserless REST base URL, without a path. Default `https://chrome.browserless.io`. |

## Troubleshooting

| Problem | What to do |
|---------|------------|
| Step times out | Raise the step's `timeout_s`. Heavy pages can take longer than the default. |
| Scrape returns nothing | Check that each `selector` in `elements` matches the page after it has rendered. |
| `401` or quota errors | Check the token and your plan limits in your Browserless account. |
| Need page options (size, margins, full page) | `options` on `browserless_capture_screenshot` and `browserless_generate_pdf` is passed straight to Browserless. See the Browserless documentation for the available options. |
