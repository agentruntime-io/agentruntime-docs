Platform **v0.1.0** — the first release of the AgentRuntime platform, shipped in late April / early May 2026.

## Console

Workspaces could manage **subscriptions and billing status** from Console for the first time. The UI connects to Stripe-backed checkout — the starting point for later multi-product billing and usage dimensions in v0.1.1+.

## API and platform

The public API received production-oriented **logging and rate limiting** so Console and early API consumers could run reliably.

AgentRuntime also fixed how **connector credentials** are resolved so workspace connector instances use the right secrets when workflows call tools.

## Workflows

Run and step logging improved — groundwork for Operate and Command Center views that ship in later releases.
