Platform **v0.1.0** — initial semver tags across core services (`webapp`, `bff`, `go-wheelhouse`, `control-service`, `agentruntime`). Repos were tagged incrementally in late April / early May 2026; no GitHub release pages were published for this wave.

## Console

Tenants could manage **subscriptions and billing status** from Console for the first time. The UI wired through the BFF to Stripe-backed checkout on the billing service — the starting point for later multi-product billing and usage dimensions in v0.1.1+.

## API and control plane

The BFF received production-oriented **logging, rate limiting, and server configuration** so Console and early API consumers could run against shared dev and staging stacks reliably.

The control plane tightened **MCP connection credential** resolution so tenant connector instances pick up the right secret paths when workflows call tools.

## Workflows

The runtime engine tagged alongside this wave with improved **run and step logging** — groundwork for Operate and Command Center views that ship in later releases.
