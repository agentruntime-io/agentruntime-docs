Platform **v0.1.0** — the first coordinated release across AgentRuntime's services, shipped in late April / early May 2026.

## Console

Tenants could manage **subscriptions and billing status** from Console for the first time. The UI connects to Stripe-backed checkout — the starting point for later multi-product billing and usage dimensions in v0.1.1+.

## API and platform

The public API received production-oriented **logging, rate limiting, and server configuration** so Console and early API consumers could run reliably.

AgentRuntime tightened **MCP connection credential** resolution so tenant connector instances pick up the right secret paths when workflows call tools.

## Workflows

The runtime engine tagged alongside this wave with improved **run and step logging** — groundwork for Operate and Command Center views that ship in later releases.
