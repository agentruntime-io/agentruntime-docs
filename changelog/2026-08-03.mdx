**Platform v0.3.1** is a focused patch on [v0.3.0](/changelog/2026-07-22): workflow wiring correctness, step timeout behavior, Workspace Chat reliability, and Connections polish.

## Workflow Studio and runs

**MCP-to-LLM chains** — when you wire an MCP tool step into an LLM step using field mapping, the run engine now keeps those dependencies in `depends_on`. Previously, some chains could start the LLM step before the MCP step finished supplying inputs.

**LLM step timeouts** — LLM calls and long-running workflow steps use improved timeout handling, reducing hung runs when a provider stalls.

## Connections

**Google account connect** — the Google account connection form has better structure and accessibility for linking Workspace accounts.

## Workspace Chat

**Offline drafts** — message drafts are preserved more reliably when you lose connectivity while composing.

## API and agents

**Agent turn credentials** — agent turn requests include model reference and credential context so downstream execution picks the intended model and key (**API only** — no Console UI change).
