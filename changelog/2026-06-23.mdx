**Platform v0.2.1** builds on [v0.2.0](/changelog/2026-06-20) (conversation workflows and Continue on limit).

## Workspace Chat

**Message queue** — if a turn is still running, new user messages wait with `queued` status and are sent when the agent is free, instead of failing or spawning duplicate runs. Users can cancel queued messages before they are sent.

**Composer drafts** autosave unsent text scoped to workspace, user, conversation, and optional thread — pick up where you left off on another device.

**Archive** moves conversations out of the active inbox while preserving history and recording who archived and when.

**Reload recovery** and **Continue on limit** sidebar UX work together: after refresh, Space restores the Continue prompt from the saved turn state.

**Isolated conversations** keep DM and agent-room Autopilot conversations from sharing run state.

## Console

**Resend verification email**, clearer auth error copy, **password change**, and more reliable session refresh reduce friction in sign-in and account recovery flows.

## API and permissions

Public API routes now enforce stronger permission checks aligned with membership capabilities and PAT scopes. If an integration suddenly receives `403`, verify the token's scopes and the user's project or workspace permissions — not only legacy role names.

OAuth profile updates, password change, PAT creation, MCP execute, onboarding, and billing all follow the same permission model.

**Lifecycle accountability** gives admins a clearer audit trail: who archived a conversation, who deleted a message, and when records changed — without relying on boolean `is_deleted` flags.
