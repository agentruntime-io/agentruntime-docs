**Platform v0.10.5** updates how Autopilot handles conversations in Console and Workspace Chat.

## Workspace Chat and Autopilot

**Ask vs Autopilot** — each turn decides its mode from your message. Ask answers read-only; Autopilot may use Platform MCP and Console UI actions.

**Console actions** — Autopilot responses can drive navigation and Studio spotlight behavior in the Console when used with Workspace Chat.

## Workflow Studio

**Graph dry-run** — run validation from Studio before publish; validation results are stored with workflow versions.
