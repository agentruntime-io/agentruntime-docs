Platform **v0.1.3** — an integrations and chat increment shipped June 3–7.

## Console

**Google connections** landed end-to-end: browse the service catalog, link a Google account from settings, and adjust scopes with the PUT endpoint — no full re-auth round trip for small scope changes.

**Password reset** completed the auth story alongside invite and password login. The **execution panel** surfaced structured failure JSON and formatted outputs when triaging workflow runs from Studio or Autopilot.

## Workflows

**Human-in-the-loop** steps publish **realtime events** when a run pauses for approval — you see pending tasks in Command Center without polling run status.

## Workspace Chat

Space shipped its **first channel UI**: send messages, react, see who's online, and open modals for channel settings. Mock-data mode in README lets developers run Space locally before live-mode prerequisites ship in v0.1.5.

## Connectors

The **Gmail** adapter and Go MCP connectors received configuration and documentation fixes — clearer errors when OAuth or tool config is misconfigured at install time.
