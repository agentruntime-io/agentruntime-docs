Platform **v0.1.1** — the largest release before mid-June 2026, shipped over May 9–22.

## Console

**Onboarding** became a first-class flow: accept an invite, pick an available workspace code, update workspace settings, and preview the product before landing in Console.

**Autopilot** gained a workflow editor with smarter naming, better run-event analysis (including credential failures), and tighter execution-panel integration — the bridge between chat intent and published workflows.

**Workflow Studio** took its first step away from client-only simulation: validate graphs on the server, read dry-run summaries, and jump from a failing step back to the canvas. The log viewer made long run traces readable without leaving Studio.

**MCP** connector profiles and connection management improved in Console. **Guided tours** and **product analytics** shipped.

## API and integrations

The public API added **inbound webhooks**, **workflow webhook** routing, **run listing and timeseries**, **LLM provider validation**, **billing usage recording**, and **PAT** metadata. New workspaces could **auto-start a trial** on creation.

Workflows gained **Lua script steps** for lightweight transforms — an early building block for custom logic before native step types expanded in v0.1.2.
