**Platform v0.3.0** ships MCP validation hardening, workflow pins, team management improvements, and OAuth2 discovery for MCP connections. This release builds on [v0.2.3](/changelog/2026-07-05) (Execution Timeline) and [v0.2.2](/changelog/2026-07-04) (template resolver stability).

## Workflow Studio and runs

**MCP input validation** — when configuring MCP tool steps, Workflow Studio now validates arguments against the tool's JSON Schema before you start a run. The engine applies schema defaults and type coercion at execution time, reducing silent failures from malformed tool calls.

**Workflow pins** — pin workflows you use frequently for one-click access from the Studio list.

**LLM model source** — agent-call step configuration shows which model source and key status apply, making it easier to diagnose missing or expired API keys.

## Connections and integrations

**OAuth2 MCP discovery** — MCP instances that require OAuth2 can use standard discovery endpoints during connection acquisition. Google account management in Connections has improved linking and display.

## Team and workspace management

**Tenant auth policy** — workspace admins can configure authentication policies and project-level access controls. Team maintainer checks ensure only authorized members can manage team settings.

## Billing

**Billing profile rollup** — billing profiles can aggregate across tenant hierarchy nodes. Webhook handlers support billing event notifications (**API only** — Console billing UI unchanged).

## Workspace Chat

**Session model consistency** — chat sessions now apply the model from the user's message payload, improving consistency when switching models mid-conversation.

## API and platform foundations

**Audit and memory baselines** — database schema foundations for audit event storage and memory kernel persistence are in place for upcoming features (**Preview**).

**Work service** — file metadata patch operations handle partial updates more consistently (**API only**).
