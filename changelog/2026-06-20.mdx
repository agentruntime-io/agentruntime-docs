**Platform v0.2.0** brings agent and workflow execution together. It also includes the June work on contacts, the Work route, and Space-to-work links.

## Workspace Chat and Console

**Conversation workflows** are the headline change: send multiple messages in an Autopilot DM or an agent room and the platform keeps one workflow **run** for the conversation. Command Center and the run view show the same run ID across turns.

**Continue on limit** ships in v0.2.0 for both Console and Workspace Chat. When a turn stops at the configured tool-round cap, the UI shows an awaiting state and a **Continue** control; the same run resumes. Reload the page mid-stream and turn status restores from the API.

Contacts (user and workspace), a **tablet layout**, and **work integration** let you jump to tasks and files from Space. Console gains a dedicated **Work** route and clearer **MCP bridge** setup for project tool wiring.

Console Autopilot shows limit/paused run visibility in the **Execution panel**; Space shows a status indicator and blocks the composer until Continue is resolved.

## Workflows

Published workflows with **`agent_call`** steps now run with lower latency. Handoffs, MCP tool rounds, and episode pause/resume behave consistently in Workflow Studio runs and in chat-bound conversation workflows.
