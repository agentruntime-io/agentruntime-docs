Platform **v0.1.4 / v0.1.5** — the last coordinated release before the unified execution program described in [v0.2.0](/changelog/2026-06-20).

## Console

**Operate** is the daily operator surface: triage runs from an inbox, manage cron schedules and inbound webhooks, and glance at workspace health — without jumping through Studio for every task.

**Workflow Studio** validates graphs on the server before you publish. Dry-run summaries link back to the canvas so you can fix failing steps quickly. Auto-layout, X-ray layers, and the template gallery speed up authoring for larger graphs.

**Triggers and LLM** round out builder workflows: configure cron, webhook, or API triggers with payload preview; pick models from the workspace catalog; test credentials before agents use them in production runs.

**Vault** gives tenants a first-class secrets UI — browse paths, edit values, and understand security boundaries before wiring credentials into workflows or MCP instances.

## Workspace Chat

Space gains **project linking** on channels so team chat stays scoped to the right automation context.

## API and billing

Public API adds workflow trigger management, LLM model validation, support/playbook endpoints, and platform event relay. Billing uses the multi-product Stripe integration — each plan carries a `product_code` instead of legacy product IDs.
