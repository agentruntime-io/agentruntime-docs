**Platform v0.10.4** (Console **v0.21.0**, work-service **v0.5.0**) improves connected workflows, conditional steps, and inbound webhook setup when reusing the same integration connection.

## Workflow Studio

**Sub-workflow input** — when a child workflow should see the parent's trigger payload, enable passing parent `input` on the Sub-workflow step instead of copying fields manually.

**skip_when** — mark steps that should not run when a Lua/expression condition is true; dry run surfaces actionable suggestions when templates or guards look wrong.

## Inbound webhooks

**Shared connection** — if a Telegram (or other vendor) inbound route already exists for a connection on another workflow, pick that connection on a new workflow to attach another subscription on the same vendor URL (fan-out).

## Billing

**Trial status** — workspace admins see clearer messaging before trial end and after trial expiry on Plans.
