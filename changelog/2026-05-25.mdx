Platform **v0.1.2** — a workflow and billing increment shipped May 25.

## Workflows

Authors could fan out work with **`for_each`** — pass an array into a step and run downstream nodes in parallel for each item. Combined with the new **workflow memory**, agent episodes could carry state forward across steps.

Command Center and early Operate APIs gained **run summary aggregation**: see pass/fail counts and step rollups without opening every log line.

## Console and billing

Billing moved toward **workspace-scoped profiles** with clearer usage-dimension rollups — the model later used for multi-product Stripe plans in v0.1.5.

Console and Space gained links to each other, ready for Workspace Chat in v0.1.3.

## API

Console sign-in and workspace context now carry through to Workspace Chat APIs, ready for the next release.
