Platform **v0.1.2** — a workflow-engine and billing increment shipped May 25.

## Workflows

Authors could fan out work with **`for_each`** — pass an array into a step and run downstream nodes in parallel for each item. Combined with the new **memory kernel**, agent episodes could carry state forward across steps — foundational pieces for unified execution in v0.2.0.

Command Center and early Operate APIs gained **run summary aggregation**: see pass/fail counts and step rollups without opening every log line.

## Console and billing

Billing moved toward **tenant-scoped profiles** with clearer usage-dimension rollups — the model later used for multi-product Stripe plans in v0.1.5.

Console config picked up **chat and platform referral** URLs so Console and Space could deep-link to each other once Workspace Chat shipped in v0.1.3.

## API

The public API gained session header injection for chat — Console auth tokens and workspace context flow through to Workspace Chat APIs in the next release wave.
