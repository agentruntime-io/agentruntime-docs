**Platform v0.2.2** records what is **live in production** as of 4 July 2026. This release builds on [v0.2.1](/changelog/2026-06-23) (message queue, stronger API permissions, lifecycle accountability).

## Workflows and runs

**Template resolver hardening** — if a workflow step uses a text template with an optional input left empty, the step now **fails with an explicit error** instead of interrupting run processing. Runs should no longer remain stuck in **Running** for this condition. See [Troubleshooting](/platform/troubleshooting) if you observed stuck runs before this deploy.

## Workspace Chat

**Starter payload patches** — updating a starter message can merge a partial `payload` object without replacing the entire JSON blob. Copilot DM session filtering is more reliable when listing conversations bound to workflow starters.

Session and preferences APIs return clearer validation errors when required fields are missing or malformed.

## Console and billing

**Billing rate limits** protect checkout and entitlement endpoints from burst traffic. If your integration receives repeated `429` responses, back off and retry rather than hammering the endpoint.

Discount code validation and membership backfill were tightened to reduce inconsistent tenant billing state after signup edge cases.

## API and integrations

MCP catalog execute routes benefit from improved authorization checks and service-name extraction — integrations using PATs should verify scopes if they suddenly receive `403` after deploy.

**Work files** document patch semantics are more consistent for partial field updates (**API only** — no dedicated Console UI yet).
